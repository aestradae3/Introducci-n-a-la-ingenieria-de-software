# Introduccion-a-la-ingenieria-de-software
Examen Práctico 2: Git y GitHub

Descripción del proyecto

Este repositorio fue creado como parte del Examen Práctico 2, con el objetivo de aprender y aplicar los conceptos básicos del control de versiones utilizando Git y GitHub.

Durante esta actividad se realizaron ejercicios prácticos para conocer cómo crear repositorios, agregar archivos, registrar modificaciones mediante commits y publicar los cambios en GitHub.

Objetivos

*Comprender el funcionamiento de Git y GitHub.

*Aprender a crear y administrar repositorios.

*Utilizar comandos básicos de Git.

*Registrar los cambios realizados mediante commits.

*Practicar el trabajo colaborativo entre los integrantes del equipo.

Herramientas utilizadas

*Git: sistema de control de versiones.

*GitHub: plataforma para almacenar y compartir repositorios.

*Visual Studio Code: editor de código.

Actividades realizadas

*Creación de un repositorio público en GitHub.

*Creación del archivo README.md.

*Clonación del repositorio.

*Creación y modificación de archivos.

*Registro de cambios mediante tres commits.

*Publicación de los archivos en GitHub.

Conclusión

Esta actividad permitió conocer la importancia del control de versiones y aprender a utilizar Git y GitHub para guardar, organizar y compartir los cambios realizados en un proyecto.
